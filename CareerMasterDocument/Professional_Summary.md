# Professional Summary & Executive Profiles (Master Repository)

> **Template Purpose:**  
> This file is a **Master Professional Summary Repository**. It stores modular, role-specific executive summaries (profiles / elevator pitches) targeting different career tracks.  
> When crafting a tailored CV, an AI agent will read this file, match the target job description to the closest profile variant, and generate a **punchy, 3- to 4-line summary (50–80 words)** that instantly highlights the candidate's core skills and quantifiable value to recruiters and ATS scanners.

---

## 📐 The High-Converting 3–4 Line Summary Formula

An AI or user building a summary should follow this proven architecture:

```
Line 1: [Seniority / Professional Identity] + [Years of Experience / Scope] + [Core Specialization]
Line 2: [Key Technical Capabilities] + [Primary Tech Stack & Architecture Patterns]
Line 3: [Flagship Quantifiable Achievement] (Proof of scale, %, latency, revenue, or automation)
Line 4: [Target Value Proposition] (How you solve the employer's upcoming challenges)
```

## 🤖 Instructions for AI CV-Crafting Agent

> 1. **Strict Length Limit:** The generated summary on the final CV must be **strictly 3 to 4 lines (50–80 words maximum)**. Never create long, multi-paragraph summaries for a resume header.
> 2. **Target Matching:**  
>    - Read the job title and core requirements from the employer's job description.
>    - Select the matching variant from the bank above (or synthesize using the Modular Sentence Bank).
>    - Directly inject the employer's target job title into the first line (e.g., *"Senior Platform Engineer with 4+ years..."*).
> 3. **Rule of Verification:** Pull hard metrics exclusively from [Achievements.md](Achievements.md) or [Work_Experience/job1.md](Work_Experience/job1.md). Never invent unrecorded percentages or metrics.
> 4. **No Fluff Policy:** Ban hollow self-descriptors (*"hardworking"*, *"detail-oriented"*, *"dynamic professional"*, *"team player"*). Demonstrate qualities through concrete stacks and measurable results.
