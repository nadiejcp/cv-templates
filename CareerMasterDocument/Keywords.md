# ATS Keywords Matrix (Master Repository)

> **Template Purpose:**  
> This file is a **Master ATS (Applicant Tracking System) Keyword Matrix**. It organizes technical, methodological, and domain-specific terms across your career.  
> An AI agent will cross-reference this matrix against the target job description to ensure 100% keyword coverage, expand acronyms, and naturally embed critical terms into your tailored CV bullet points without awkward "keyword stuffing."

---

## 💡 How to Organize Keywords for Maximum ATS Impact

> [!TIP]
> **ATS Keyword Best Practices:**  
> 1. **Dual Acronym & Full Form:** Include both forms (e.g., *LLMs / Large Language Models*, *RAG / Retrieval-Augmented Generation*, *CI/CD / Continuous Integration*) because different ATS algorithms search for different variants.
> 2. **Cluster by Functional Role:** Group keywords under the exact specialization names recruiters use in Boolean search strings.
> 3. **Tool Ecosystems:** Group related tools together (e.g., *Docker, Kubernetes, Helm, Containerd*) so the AI can tailor breadth vs. depth.
